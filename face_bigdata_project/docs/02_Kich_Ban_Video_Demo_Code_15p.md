### HƯỚNG DẪN CHUẨN BỊ KỸ THUẬT KHI QUAY
1. **Âm thanh:** Dùng micro có lọc ồn (hoặc tai nghe điện thoại), nói to rõ, tự tin, phát âm chuẩn các thuật ngữ chuyên ngành (ArcFace, FAISS, Inverted File, Product Quantization, Micro-batch, Latency, Throughput).
2. **Độ phân giải video:** Đặt màn hình ở độ phân giải Full HD (1920x1080), tỷ lệ 16:9, tốc độ 30 hoặc 60 FPS để hình ảnh chữ trong code và biểu đồ hiển thị sắc nét nhất.
3. **Thao tác chuột:** Di chuyển chuột dứt khoát, chỉ đúng vào các con số quan trọng (96% RAM, 0.35ms Latency, 80% Parquet compression) khi đang thuyết minh.
